# Tableau deliverables

Open **Retention_Analytics.twbx** in Tableau Desktop **2026.1+**.

- Two dashboards: Retention Overview and Customer Worklist.
- Ten editable worksheets and four embedded CSV sources.
- Risk, segment and acquisition-channel filters on the worklist.
- `validation.json` records official XSD, field reference and package verification results.

Native Tableau rendering has **not** been verified because the application is unavailable in the build environment. The workbook passes structural/schema checks; that is not a native-open guarantee.

See [the full guide](../docs/tableau.md) for interpretation, correct aggregations, refresh instructions, filter scope and the separate native forecast comparison worksheet.
